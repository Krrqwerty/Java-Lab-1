#OOPS Lab 1 - Java Environment
Description
This repository contains the first lab assignment for Object-Oriented Programming (OOPS) in Java. It includes concepts such as the Java Development Kit (JDK), Java Runtime Environment (JRE), and Java Virtual Machine (JVM), along with practical exercises.

Contents
Explanation of JDK, JRE, and JVM
Steps to install and verify the Java Environment
A simple "Hello, World!" program with compilation and execution steps
Program to display name and address in different lines
Prerequisites
Install JDK 23 or the latest available version
Set up environment variables (PATH and JAVA_HOME) correctly
How to Run
Open a text editor (Notepad, VS Code, etc.)
Write a simple Java program (HelloWorld.java)
Compile using:
nginx
Copy
Edit
javac HelloWorld.java
Run the program:
nginx
Copy
Edit
java HelloWorld
